# Benchmark fixtures

The committed Caesar files are deliberately tiny synthetic fixtures for testing
contracts, content identities, and an oracle-scored exhaustive transform. The
worker is given the disclosed plaintext and therefore does not perform
cryptanalysis. These files are not the scientific benchmark proposed in the
blueprint and provide no evidence about the Voynich manuscript.

Production benchmarks require provenance-reviewed historical corpora, multiple
cipher/generator families, noise models, adversarial controls, whole-work
partitions, rotating sequestered answers, and custodian-independent evaluation.

The repository owner should choose explicit software, documentation, and fixture
licenses before accepting outside contributions. Until then, the source manifest
records that legal choice as pending rather than pretending the empty
repository's materials already shared one license.
