# Calibration (Gate 2 tooling)

Inputs and outputs of `voynich plant`, `voynich sweep` and `voynich calibrate`.
Method, results and the recommendation are in `docs/CALIBRATION.md`.
Planted answers are public in this development phase; under the protocol the
custodian holds them until after the run.

| File | Purpose |
|---|---|
| `grid_selfcite_v1.json` | Coarse development grid for the self-citation family: 216 points, 8 replicates |
| `grid_selfcite_v1_refined.json` | Refinement level around the best coarse region: 81 points |
| `planted-on-grid/`, `planted-off-grid/` | Planted pseudo-manuscripts: answer, target, generated text (layout and resources are regenerated by `plant`) |
| `report-*.json` | Calibration reports: thresholds, recovery, compatible points, controls, raw self-distances |

The full ledgers (`*.ledger.jsonl`, every replicate's distance and fingerprint) are not committed; `voynich calibrate` recreates them byte for byte.
