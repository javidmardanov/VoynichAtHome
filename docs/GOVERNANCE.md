# Governance and scientific claims

The human repository owner, Javid Mardanov, is the project owner and release authority. Automated coding and checking assist that work. There is currently no appointed advisory board, independent benchmark custodian, or volunteer council. The project must not imply that these roles exist or that an outside institution endorses it.

The [current design](DESIGN.md) governs implementation. The former multi-committee proposal remains in [history](history/blueprint-GOVERNANCE.md); its proposed institutions and BOINC process are not current requirements.

## Experiment admission

Researchers propose experiments through the structured GitHub issue form. A proposal states the question, data and rights, previous exposure, exact algorithm and budgets, controls, stopping rules, failure interpretation, and reproduction procedure. The owner records whether it is accepted, deferred, or declined and why. Method changes create a new manifest; completed campaigns need a new declared continuation.

Volunteers run only approved modules and experiment types. A proposal cannot upload arbitrary executable code. More computation requires a useful measurement or search, including a declared test of whether additional starts help. Empty queues are acceptable.

## Review arrangements

Source review, automated checks, trusted execution replay, independent reproduction, and specialist scientific review are different activities. Reports identify which actually occurred and link the evidence. The present recovery tests conceal messages and keys from the solver; they are administered by the same project that develops the solver. They are not independently administered tests.

Outside reviewers can contribute through public issues and pull requests. Record their actual role, findings, conflicts, and permission to be acknowledged. A reviewer name or institution must never be invented. Reproducing a result does not automatically endorse its interpretation.

## Publication and correction

Public pages distinguish completed computation, a promising candidate, and a supported scientific conclusion. Credit measures checked work under the published estimate. It never measures truth or the proportion of the manuscript decoded.

A manuscript candidate includes actual mapping rules, unchanged decoder output, substantial coverage, unparsed symbols, exceptions, and registered comparisons. Advancement requires independent reproduction and relevant specialist scrutiny. Attractive isolated words are insufficient. Existing manuscript analyses remain exploratory because of previous whole-manuscript exposure.

Publish failures and negative controls with successful runs. Link corrections or withdrawals to the original immutable records. Do not describe finite adaptive search coverage as exclusion of an entire continuous domain, or an execution interruption as evidence against a hypothesis.

## Resources and ownership

The initial operating target is $10 per month, with owner approval before paid setup. Provider billing and application reserves are separate. Keep hosted checking independent of the owner's computer and reserve capacity for already issued work before assigning more.

Original code and documentation use MIT; imported materials retain their terms. Sponsors and outside support are disclosed. No cryptocurrency, mining, tokens, speculative rewards, or hidden unrelated workloads are permitted.

The owner can pause campaigns, stop assignments, revoke releases, and moderate public names and teams. Account deletion removes public identity while preserving research records without it. A security incident requires a remediation record and owner approval before reopening affected work. Public release remains an owner decision after the documented acceptance checks.
