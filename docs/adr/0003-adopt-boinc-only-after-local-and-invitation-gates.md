# Adopt BOINC for public execution only after local and invitation gates

Voynich@Home will reuse BOINC rather than build a public volunteer client for v1,
but no BOINC rollout begins until local known-answer, false-positive, security,
privacy, and energy gates pass. The first public-capable worker will be a reviewed,
offline-signed, single-purpose native application; arbitrary or Universal Docker
workloads trade useful packaging flexibility for an unacceptable gap in the
initial per-workload signing and sandbox story.
