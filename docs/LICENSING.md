# Licensing

Original project code and original documentation use the [MIT license](../LICENSE). Third-party terms take precedence for their material. The owner authorized an open-source release; MIT is the selected permissive default.

The [source registry](../catalog/source-registry.json) records each source, version, digest, attribution and rights. The host declares collected transliterations CC0. That does not license the EVA Hand 1 font, images, or unrelated implementations. No restricted font is bundled. Images and comparison works need separate rights records before redistribution.

Imported Naibbe material must retain its modified MIT license and required scholarly citation. GPL source must not be copied into MIT-only modules. Package dependencies retain their licenses. Generated research bundles include provenance and third-party notices.
