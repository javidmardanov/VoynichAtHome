# Licensing

Original project code and original documentation use the [MIT license](../LICENSE). Third-party terms take precedence for their material. The owner authorized an open-source release; MIT is the selected permissive default.

The [source registry](../catalog/source-registry.json) records each source, version, digest, attribution and rights. The host declares collected transliterations CC0. That does not license the EVA Hand 1 font, images, or unrelated implementations. No restricted font is bundled. Images and comparison works need separate rights records before redistribution.

Imported Naibbe material must retain its modified MIT license and required scholarly citation. GPL source must not be copied into MIT-only modules. Package dependencies retain their licenses. Generated research bundles include provenance and third-party notices.


Worker and native archives carry dependency notices. The hosted package exposes its inventory at `/notices/README.txt`. Web notices cover the installed application dependency graph, including Svelte and SvelteKit; this conservatively includes some build support packages. Rust notices come from the actual native dependency graph.

The [supplemental npm notice registry](../third_party/npm-licenses/sources.json) preserves upstream notices missing from package tarballs. It distinguishes version source revisions from a later upstream license addition for Better Auth utilities. `is-reference` and `locate-character` publish MIT declarations in their metadata and README without a separate license file; those original declarations and documents are retained without inventing a copyright notice. New missing notices fail packaging and require review.
