Operating regression tests cover atomic month rollover reserves, funded replay retries, traffic reserve, audited delivery extensions, and interrupted/concurrent R2 imports. The module packager inspects the binary memory ceiling and records source hashes, toolchain, target, and flags. A release-candidate workflow prepares signed provenance and draft archives after the owner selects a tag; no signed production release is claimed yet.

The current local milestone passes 27 platform tests and 26 browser cases (four redundant CLI-only cases skipped), with Python recovery-harness checks passing. Additional tests cover portable R2 export/import, corruption rejection before database restoration, report score rechecking, review requirements, and manuscript admission bound to an exact reviewed model, passage and budget. This is local evidence; full deployed restoration, off-provider backup operation, and rollback still need rehearsal.

All three work types now use the Rust C ABI in the browser and native `vah-worker`: generation resumes per replicate; annealing search and verification resume per 256 proposals; beam calls remain bounded synchronous operations terminated by Stop. The previous search module remains an explicit search-only compatibility path. Worker memory is capped at 96 MiB; this is not a total browser-memory guarantee.

New search inputs store their language models and ciphertexts once as digest-checked shared R2 objects. Delivery reconstructs and checks the original scientific identity. The storage reserve includes both compact work records and shared objects. Backup manifests include those dependencies, and restoration checks them before changing D1. An interrupted, unissued import remains unassignable and requires the owner to retry it. This storage change adds migration 0005 and requires a new hosted deployment and rehearsal.

The complete 3,510-run development panel has been reproduced locally, with one retained operational timeout followed by an exact retry. The evaluation settings were published in commit `5c1ec449f218f876d6160f99e0e9d62737d6e121` before fetching the evaluation works. A total of 1,800 message-and-key cases and 5,400 comparison inputs are prepared, with zero preparation failures. The first 100-case condition (Latin, 1,000 characters, ordinary substitution; 19,500 runs including controls) is running locally on one native worker. This does not mark the full evaluation complete.

The initial hosted reserve is deliberately conservative: 30,000 ms per trusted replay and a 1,000,000 ms monthly allocation permit at most 33 first replay reservations before funded retries. Larger research campaigns require a measured hosted cost policy and an owner-approved operating allocation. No unlimited or high-throughput hosted research capacity is claimed.
