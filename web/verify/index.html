Voynich@Home — verify a registered unit in your browser

This page does one small thing, fully in your browser: it loads the science kernel as WebAssembly, checks that the module is the one the project published, runs one registered work unit, and compares the result hash with the published one. If the hashes match, you have reproduced a piece of the published computation on your own machine. Nothing is sent anywhere.

Nothing runs until you press the button. Expected duration: a few seconds.

1. Load the release manifest and the module
—
2. Check the module digest against the manifest
—
3. Run the registered work unit
—
4. Compare the result hash with the published one
—
5. Specimen: the text your machine generated for one seed
—

What this proves, and what it does not

  • A match proves that your browser's WebAssembly engine computed the same bytes as the project's native build for this unit: same generator, same statistics, same distance.
  • It does not prove anything about the manuscript. The unit is a development job on unregistered weights; results with scientific meaning come only from a registered experiment.
  • The manifest check is a digest comparison. A signed manifest and an external transparency record are planned before any public pilot (see docs/SYNTHESIS.md, section 6).
